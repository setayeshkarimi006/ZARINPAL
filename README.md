# 🚀 پروژه هدر ریسپانسیو زرین‌پال (Responsive Header)

این پروژه یک تمرین تخصصی برای طراحی بخش هدر (Header) وب‌سایت زرین‌پال با رویکرد **Responsive Web Design** است. هدف اصلی این پروژه، نمایش صحیح المان‌ها در دستگاه‌های مختلف (موبایل و دسکتاپ) و مدیریت ساختار منو است.

---

## 🛠 تکنولوژی‌های استفاده شده
- 💻 **HTML5**: برای ساختار معنایی صفحه.
- 🎨 **CSS3**: طراحی استایل‌ها، Flexbox، و مدیریت ریسپانسیو.
- 📱 **Responsive Design**: استفاده از Media Queries برای نمایش بهینه در موبایل و دسکتاپ.
- 🖱 **Interactive Elements**: استفاده از تکنیک `input:checkbox` برای باز و بسته کردن منوی همبرگری بدون نیاز به جاوا اسکریپت.

---

## ✨ ویژگی‌های پروژه
- [x] **طراحی ریسپانسیو:** هدر کاملاً با سایزهای مختلف صفحه سازگار است.
- [x] **منوی همبرگری:** در موبایل، منو به صورت بهینه و کاربرپسند نمایش داده می‌شود.
- [x] **CSS مدرن:** استفاده از Flexbox برای چیدمان مرتب المان‌ها.
- [x] **کد تمیز:** رعایت ساختار معنایی برای دسترسی‌پذیری بهتر.

---

## 📂 نحوه اجرا
برای مشاهده پروژه، کافیست فایل `index.html` را در مرورگر خود باز کنید. نیاز به نصب هیچ‌گونه ابزار خاصی ندارید!

---

## 💡 آموخته‌های من در این پروژه
- کار با `Media Queries` برای شکستن چیدمان در نقاط مختلف.
- رفع مشکلات چسبندگی هدر (`position: sticky`).
- مدیریت فضاهای خالی و جلوگیری از سرریز شدن محتوا (`overflow-x: hidden`).
- پیاده‌سازی منوی تعاملی بدون نیاز به کدنویسی پیچیده جاوا اسکریپت.
